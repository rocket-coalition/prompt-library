# 🌈 **WHAT CSS ACTUALLY DOES**

CSS controls **four core things**:

### **1. LOOK**

Color, background, gradient, fonts, shadows.

### **2. SIZE**

Width, height, padding, margin.

### **3. POSITION**

Where things sit on the page (left/right/top/bottom).

### **4. BEHAVIOR**

Hover states
Animations
Transitions
Effects

---

# 🧱 **HOW CSS WORKS — THE MOST IMPORTANT IDEA**

CSS is made of **rules**.

A rule says:

> “When you see an element that matches *this selector*,
> apply *these styles* to it.”

Example:

```css
p {
  color: blue;
  font-size: 18px;
}
```

This means:

> “All `<p>` tags should be blue, size 18.”

That's it.
CSS is just a giant rulebook.

---

# 🧲 **SELECTORS — HOW CSS POINTS AT THINGS**

Selectors are like laser pointers.

### 🔹 **Element Selectors**

```css
h1 { color: red; }
```

### 🔹 **Class Selectors**

You label a thing:

```html
<div class="profile"></div>
```

CSS styles it:

```css
.profile { background: #eee; }
```

### 🔹 **ID Selectors (rare)**

```html
<div id="hero"></div>
```

```css
#hero { height: 600px; }
```

### 🔹 **Wildcard Selectors**

```css
* {
  margin: 0;
  padding: 0;
}
```

This hits EVERYTHING.

---

# 📦 **THE BOX MODEL — THE HEART OF CSS**

Every element is a **box**.

Every.
Single.
One.

Even text.

Each box has:

```
+-----------------------------+
|       margin (outside)      |
| +-------------------------+ |
| |      border            | |
| | +---------------------+| |
| | |  padding (inside)   || |
| | | +-------------------+| |
| | | |   content         || |
| | | +-------------------+| |
| | +---------------------+| |
| +-------------------------+ |
+-----------------------------+
```

This is where most newbies get confused.
It’s literally just **boxes inside boxes**.

---

# 🧭 **LAYOUT — HOW THINGS ARRANGE THEMSELVES**

CSS gives you layout systems like:

### 📍 **1. Flexbox (for rows/columns)**

The simplest:

```css
.container {
  display: flex;
  gap: 20px;
}
```

### 🔳 **2. Grid (for advanced layouts)**

```css
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}
```

### 📜 **3. Positioning**

`absolute`, `relative`, `fixed`, `sticky`.

CSS is basically **gravity for the web.**
