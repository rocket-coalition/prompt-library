Signature Approaches

01

Local-API Pattern

Hugo generates /api/*.json bundles that behave like API endpoints. Powers search engines and dashboards.

02

Hugo as Data-Orchestrator

Import content from external sources at build time. CSV → JSON conversions, schema-driven automation.

03

Faux Server Architecture

HTMX + Alpine.js mimics server logic client-side. User accounts via localStorage, static side effects.

04

Fragment-Driven UI

Hugo outputs html-fragments/ and json-api/. HTMX loads on-demand, creating an active backend illusion.

Engineering Philosophy

Local-first, server-last — only use a backend when essential
Performance is UX — fast always beats complex
Static ≠ simple — static sites can behave like apps
Data belongs in structures, not in templates
HTML-first design — let HTML do the work
If Hugo doesn't support it… extend Hugo
