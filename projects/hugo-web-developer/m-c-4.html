About

Static doesn't mean simple.

I'm a boundary-breaking developer who sees Hugo as more than a static site generator — it's a complete application platform. While others reach for heavy frameworks and complex backends, I achieve the same results with zero server complexity.

My approach combines build-time intelligence with lightweight runtime interactivity. The result? Sites that load instantly, work offline, and feel as dynamic as any SPA — all deployable on a simple CDN.
